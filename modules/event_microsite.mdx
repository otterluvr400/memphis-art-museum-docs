## Business Logic

### Event Hero Layout

The `event_hero_layout` template replaces the standard event details with a custom hero section:

1. **Ambient background image** — uses event's `image_1024` as a full-width background
2. **Hero inner card** — 60% width centered, white background, rounded corners
   - Left panel (60%): event image with 5:4 aspect ratio
   - Right panel (40%): event title, date, location, ticket price, registration CTA
3. **Sponsors grid** — animated sponsor flags with logo/name, tier badge, and staggered animation delays
4. **Event description** — rendered below the hero in a container

### Shop Layout Overrides

`views/shop_layout_overrides.xml` makes four shop-wide changes:

1. **Remove attribute filter sidebar** (`products_attributes_removed`) — removes the `#wsale_products_attributes_collapse` div. The comment notes a single "Option" attribute carries 267 junk values from imports.
2. **Remove category breadcrumb** (`products_breadcrumb_removed`) — removes `website_sale.products_breadcrumb` from shop pages. Root `/shop` and product page breadcrumbs are unaffected.
3. **Reorder product detail sections** (`product_details_options_order`) — uses CSS flex `order` to render: name → options → price → CTA.
4. **Remove "All products" breadcrumb link** (`product_breadcrumb_no_all_products`) — removes the root link from product page breadcrumbs to keep users within their collection line.

## Native Odoo 19 Comparison

### `product.template._service_tracking_blacklist`

**Native Odoo 19:** Excludes certain service tracking types (including `"event"`) from appearing in some contexts.

**This module:** Removes `"event"` from the blacklist, allowing event products to appear wherever the blacklist is consulted.

**Why it matters:** Event products can now be used in contexts where they would normally be hidden.

### `product.template._get_saleable_tracking_types`

**Native Odoo 19:** Returns a fixed set of saleable tracking types.

**This module:** Appends `"event"` to the list if not already present.

**Why it matters:** Ensures event products are recognized as saleable.

### Event Page Layout

**Native Odoo 19:** Standard event description page with basic event details.

**This module:** Replaces the entire layout with a custom hero section, sponsor grid, and ambient background.

**Why it matters:** Complete visual overhaul of event pages. Any upstream changes to `website_event.event_description_full` may conflict.
