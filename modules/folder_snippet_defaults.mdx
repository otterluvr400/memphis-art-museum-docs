## Business Logic

<Steps>
  <Step title="Folder record is written">
    `WebsiteFolder.write()` calls `super().write(vals)` first, then checks the context flag `skip_snippet_default_sync`.
  </Step>
  <Step title="Sync condition">
    If `skip_snippet_default_sync` is absent and any of `SYNC_FIELDS` (`banner_hero_image`, `banner_tagline`) changed, `_sync_snippet_defaults()` is called.
  </Step>
  <Step title="Resolve websites">
    For each folder, the method collects all `website_ids` from `folder.website_group_id` plus `group.base_website_id` if set.
  </Step>
  <Step title="Find homepage views">
    Searches `ir.ui.view` for records where `key = "website.homepage"` and `website_id` is in the collected websites.
  </Step>
  <Step title="Apply markers">
    `_apply_snippet_defaults_to_view(view)` parses `arch_db` with `lxml.html`, finds elements with `data-folder-asset` in `SYNC_FIELDS`, and updates:
    - Image fields on `<img>` tags: sets `src` to `/web/image/website.folder/{folder.id}/{field_name}`.
    - Text fields: replaces element text and removes child elements.
  </Step>
  <Step title="Write back">
    If any element changed, the new arch is serialized and written to the view with `skip_snippet_default_sync=True` to prevent recursion.
  </Step>
</Steps>

<Warning>
  The `write()` override shadows the base `website.folder.write()` from `web_foldering_architecture`. It does call `super().write()`, but any upstream `write` logic in the dependency chain runs before snippet sync. Confidence on recursion safety is **medium** because the recursion guard is local to this module's context key.
</Warning>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Snippet defaults not updating on homepage">
    Check that the folder has a `website_group_id`. Without a group, `_sync_snippet_defaults()` skips the folder silently.
  </Accordion>
  <Accordion title="Recursion on write">
    The sync re-write uses `skip_snippet_default_sync=True`. If another module writes the same view without that context key, recursion is possible.

  <Accordion title="Homepage not found">
    `_sync_snippet_defaults()` searches only `ir.ui.view` records with `key = "website.homepage"` and `website_id` in the group's websites. If the shell/base website's homepage uses a different key, no update occurs.
  </Accordion>

## Native Odoo 19 Comparison

### `website.folder` model

**Native Odoo 19:** Does not include a `website.folder` model. Folder/group website orchestration is custom to `web_foldering_architecture`.

**This module:** Extends the custom `website.folder` with two new asset fields and a sync mechanism.

**Why it matters:** Any integration with standard Odoo website records must go through the parent module's abstractions.

### `WebsiteFolder.write()` snippet sync

**Native Odoo 19:** Standard Odoo models do not push custom field values into view `arch_db` automatically on `write()`.

**This module:** Overrides `write()` to detect changes in `SYNC_FIELDS` and mutate `website.homepage` `arch_db` to match.

**Why it matters:** This couples folder data to view XML, so editing the folder form changes persisted homepage XML. Developers should be aware the `arch_db` is programmatically rewritten.

### `website.s_banner` template markers

**Native Odoo 19:** The native `website.s_banner` snippet does not contain `data-folder-asset` attributes; its hero text and image are edited through the website builder only.

**This module:** Adds `data-folder-asset="banner_tagline"` to the first `h1` and `data-folder-asset="banner_hero_image"` to the first hero `<img>`.

**Why it matters:** The marker attributes are invisible to end users but act as anchors for the Python sync code. Removing or renaming the snippet structure can break the sync.

### `/web/image/` route usage

**Native Odoo 19:** The `/web/image/<model>/<id>/<field>` route is the standard way to serve binary fields publicly.

**This module:** Uses that route to set the hero image `src`, matching native behavior for image delivery.

**Why it matters:** No custom image controller is required, but standard access rules and caching apply.
