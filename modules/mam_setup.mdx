## Native Odoo 19 Comparison

### Dependency-only meta module

**Native Odoo 19:** Odoo's module system lets any module declare a `depends` list to enforce installation order and to pull in required functionality. Odoo does not ship a built-in "install all custom modules" meta module for this project.

**This module:** `mam_setup` declares ten custom modules in `depends` and nothing else, creating a single install target for the entire MAM custom stack.

**Why it matters:** Installers can select one module (`mam_setup`) to bring up the full custom environment, rather than manually installing each dependency. The trade-off is that `mam_setup` becomes a single point of failure for the entire dependency graph.
