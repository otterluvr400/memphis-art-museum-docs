### `website.manipulator.upload`

- **Connection fields**: `craft_base_url` (default: `https://mam.prettyuseful.dev`), `craft_session_cookie`, `craft_csrf_token`, `craft_folder_id` (default: 1)
- **Upload fields**: `upload_file` (Binary, `attachment=False`), `upload_filename`
- **Status fields**: `last_status` (Selection: idle/ok/failed), `last_response` (Text, readonly)
- **Security**: Session cookie and CSRF token fields use `password="True"` in the form view to mask values

### `action_upload_image()`

1. Validates required fields (`upload_file`, `craft_session_cookie`, `craft_csrf_token`)
2. Constructs Craft CMS upload URL: `{craft_base_url}/index.php?p=admin%2Factions%2Fassets%2Fupload`
3. Sends POST request with:
   - Headers: `Accept`, `X-Requested-With: XMLHttpRequest`, `Origin`, `Cookie`
   - Files: `assets-upload` with decoded base64 image
   - Data: `folderId`, `CRAFT_CSRF_TOKEN`
4. On response:
   - Extracts new CSRF token from `x-csrf-token` header and updates record
   - Sets `last_status` to "ok" (HTTP 200) or "failed"
   - Stores first 2000 chars of response in `last_response`
5. On request exception: sets status to "failed" and stores exception details

## Business Logic

### Craft CMS Integration

This module provides a bridge between Odoo and Craft CMS for image asset uploads. The integration is session-based:

1. An administrator authenticates with Craft CMS and obtains a session cookie
2. The cookie and current CSRF token are stored in the Odoo record
3. The `action_upload_image` method proxies the upload to Craft's asset upload endpoint
4. After each request, the CSRF token is refreshed from the response headers

<Warning>
  The session cookie is sensitive credentials. The `password="True"` form widget masks it in the UI, but it is stored in plain text in the database. Consider using Odoo's `ir.config_parameter` or encrypted fields for production.
</Warning>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Upload fails with 403 Forbidden">
    The Craft session cookie may have expired. Re-authenticate with Craft CMS and update the session cookie and CSRF token.
  </Accordion>
  <Accordion title="CSRF token mismatch">
    The CSRF token rotates after each request. The module attempts to auto-update it from the `x-csrf-token` response header, but if a request fails before the header is sent, manual refresh may be needed.
  </Accordion>
  <Accordion title="File not found error">
    Ensure `upload_file` is set and `upload_filename` has a valid extension. The default filename is "upload.png".
  </Accordion>
  <Accordion title="Connection timeout">
    The request timeout is 60 seconds. Check network connectivity to `craft_base_url`.
  </Accordion>
</AccordionGroup>

### External CMS Integration

**Native Odoo 19:** Odoo does not include native Craft CMS integration. External system integrations typically use `ir.actions.server`, `base.automation`, or custom API modules.

**This module:** Implements a custom model with direct HTTP requests to Craft CMS's internal upload endpoint.

**Why it matters:** This is a bespoke integration tightly coupled to Craft CMS's internal API structure. Upgrading Craft CMS may break the integration.
